# ASRO × NeoMundi — LegalTech Runtime Governance Study

Status: working draft — not for public release.

This directory contains the joint runtime governance validation study conducted between:

- NeoMundi (behavioral regime evidence layer)
- ASRO (governed-state continuity witness layer)

Scenario:
`legaltech-no-direct-advice-001`

Objective:
Evaluate whether two independent witness layers can produce complementary and non-circular runtime evidence on the same execution workload without consuming each other's outputs during measurement.

Current contents include:
- working drafts,
- methodology notes,
- prompt sets,
- runtime observations,
- CSV outputs,
- non-circularity protocols,
- continuity vs behavioral divergence analysis.

This study is part of a broader effort to establish independently reviewable runtime governance methodologies for generative AI systems.
