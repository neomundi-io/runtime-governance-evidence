# Protocols

Formal runtime governance protocols associated with the ASRO × NeoMundi LegalTech study.

This directory may contain:
- non-circularity protocols,
- blind validation procedures,
- witness-layer interaction rules,
- runtime observation constraints,
- independence guarantees,
- continuity attestation boundaries,
- publication protocols,
- reproducibility procedures.

The purpose of these protocols is to ensure independently reviewable runtime governance evidence generation across multiple execution environments.
