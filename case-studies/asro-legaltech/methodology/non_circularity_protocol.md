# Non-Circularity Protocol

## Purpose

This protocol defines the separation constraints between:

- behavioral regime measurement,
- governance-state witnessing,
- provider execution,
- and post-hoc interpretation layers.

The objective is to prevent circular validation patterns in runtime governance studies.

---

# Core Principle

No witness layer may consume the output of the layer it is intended to validate during measurement.

Behavioral evidence and governance continuity evidence must remain independently generated.

---

# NeoMundi Measurement Boundary

NeoMundi measures:

- behavioral regime,
- runtime stability variation,
- coherence variation,
- hallucination indicators,
- FLAG events.

NeoMundi does NOT consume during measurement:

- declared policy constraints,
- provider self-assessments,
- governance attestations,
- legal correctness judgments,
- human annotations.

The runtime signal is generated independently from the declared governance framing.

---

# ASRO Witness Boundary

ASRO witnesses:

- declared policy continuity,
- authority posture,
- runtime governance state,
- oversight continuity,
- tool-access continuity.

ASRO does NOT consume during witness generation:

- NeoMundi G-Scores,
- runtime FLAG events,
- hallucination measurements,
- coherence outputs,
- behavioral classifications.

ASRO does not measure behavioral regime.

---

# Provider Boundary

Providers generate outputs under declared runtime conditions.

Provider self-reporting is not considered sufficient runtime evidence.

No provider internal confidence score is treated as a governance witness.

---

# Post-Hoc Correlation Rule

Correlation between:

- behavioral findings,
- governance continuity findings,
- and provider outputs

may occur ONLY after all independent witness layers have completed execution.

---

# Blind Validation Requirement

Future validation rounds should include blind prompt batches where:

- prompt authors,
- runtime observers,
- behavioral evaluators,
- and governance witnesses

operate independently before result comparison.

---

# No-Self-Witness Principle

A system cannot independently certify the stability of its own consequential execution.

This principle applies to:

- language models,
- orchestration systems,
- governance layers,
- and witness infrastructures.

---

# Claim Boundary

This protocol does NOT establish:

- legal admissibility,
- provider safety certification,
- regulatory compliance certification,
- model correctness guarantees.

The protocol establishes only:

- methodological independence,
- witness separation,
- reproducibility framing,
- and non-circular runtime evidence generation constraints.
