# Methodology

Methodological artifacts associated with the ASRO × NeoMundi LegalTech runtime governance study.

This directory may contain:
- non-circularity protocols,
- information-flow specifications,
- witness-layer definitions,
- behavioral regime definitions,
- continuity-attestation framing,
- blind validation procedures,
- reproducibility notes,
- claim-scope boundaries,
- terminology stabilization work.

The objective is to make the joint methodology independently reviewable, reproducible, and resistant to circular validation patterns.
