# Case Studies

This directory contains partner-specific runtime governance validation studies.

Each case study documents:

- experimental framing,
- provider configurations,
- prompt classes,
- runtime observations,
- behavioral regime findings,
- continuity vs efficacy distinctions,
- non-circularity boundaries,
- validation limitations,
- reproducibility notes.

The objective is to progressively build a structured body of independently reviewable runtime governance evidence across multiple environments and partners.
