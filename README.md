# Runtime Governance Evidence

## Runtime AI systems increasingly operate without independently reviewable execution evidence.

This repository explores whether:
- behavioral regime evidence,
- governance-state continuity evidence,
- and runtime execution observations

can remain independently generated while still producing complementary governance insights.

---

## The Problem

Most AI governance systems rely on:
- provider self-reporting,
- post-hoc moderation,
- static policy declarations,
- or opaque internal scoring.

This creates circular validation patterns.

The system being observed often participates in its own certification.

---

# Methodological constraints

This repository intentionally operates under constrained methodological assumptions.

The objective is not to prove universal claims about AI systems, but to explore whether:
- runtime observations,
- behavioral continuity patterns,
- and independently reviewable evidence structures

can support meaningful governance instrumentation.

Claims are intentionally limited to what the methodology can reasonably support.

----

## The Research Direction

This repository documents experimental work around independent runtime witness layers.

Two independent layers are currently explored:

### NeoMundi
Behavioral regime evidence:
- runtime stability variation,
- coherence variation,
- hallucination indicators,
- behavioral divergence observations,
- FLAG events.

NeoMundi does not consume declared governance policy during measurement.

### ASRO
Governed-state continuity evidence:
- policy continuity,
- authority posture,
- oversight continuity,
- runtime governance-state witnessing.

ASRO does not measure behavioral regime.

---

## Core Research Question

Can independent runtime witness layers observe complementary governance-relevant properties without collapsing into circular validation?
