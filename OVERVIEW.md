# Runtime Governance Evidence Repository

## Purpose

This repository documents experimental runtime governance validation work conducted across independent witness layers.

The objective is to explore whether:
- behavioral regime evidence,
- governance-state continuity evidence,
- and runtime execution observations

can remain independently generated while still producing complementary governance insights.

---

# Witness Layers

## NeoMundi

NeoMundi produces runtime behavioral regime evidence:
- stability variation,
- coherence variation,
- hallucination indicators,
- behavioral divergence observations,
- FLAG events.

NeoMundi does not consume declared governance policy during measurement.

---

## ASRO

ASRO produces governed-state continuity evidence:
- declared policy continuity,
- authority posture continuity,
- oversight continuity,
- runtime governance-state witnessing.

ASRO does not measure behavioral regime.

---

# Core Research Question

Can independent runtime witness layers observe complementary governance-relevant properties without collapsing into circular validation?
